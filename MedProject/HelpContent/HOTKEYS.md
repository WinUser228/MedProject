# Горячие клавиши

В приложении "Коечный учёт" доступны следующие горячие клавиши для ускорения работы:

## Навигация по разделам

| Горячая клавиша | Действие |
|----------------|----------|
| **Ctrl+1** | Перейти в раздел "Ввод данных" |
| **Ctrl+2** | Перейти в раздел "Справочники" |
| **Ctrl+3** | Перейти в раздел "Справка" |

## Работа с таблицами (стандартное поведение таблиц)

| Горячая клавиша | Действие |
|----------------|----------|
| **Enter** | Сохранить изменения в текущей ячейке и перейти к следующей строке |
| **Tab** | Перейти к следующей ячейке |
| **Shift+Tab** | Перейти к предыдущей ячейке |
| **Стрелки** | Перемещение между ячейками |
| **Delete** | Очистить содержимое ячейки (в режиме редактирования, работает только в таблице с движениями пациентов) |

## Раздел "Ввод данных"

| Горячая клавиша | Действие |
|----------------|----------|
| **Ctrl+S** | Сохранить данные |
| **Ctrl+R** | Открыть отчёт "Движение больных" |
| **Ctrl+Shift+R** | Открыть отчёт "Работа коек" |

Примечание: 
- **Ctrl+S** работает только если данные валидны
- Нередактируемые строки пропускаются при перемещении стрелками в таблице  

## Раздел "Справочники"

| Горячая клавиша | Действие |
|----------------|----------|
| **Ctrl+N** | Добавить новую запись (в текущей вкладке) |
| **F2** | Редактировать выбранную запись |
| **Delete** | Удалить выбранную запись |

Примечания:
- **F2** и **Delete** работают только если в таблице выбрана запись
- Нельзя удалить запись, если к ней привязаны другие данные. Это сделано в целях сохранения целостности текущих и исторических данных. (Подробнее об этом в разделе справки "Справочники")

## Дополнительная информация

Все горячие клавиши также отображаются в подсказках при наведении курсора на соответствующие кнопки в интерфейсе.

Если горячая клавиша не работает, убедитесь, что:
- Вы находитесь в правильном разделе приложения
- Выбран нужный элемент (для F2 и Delete)
- Данные валидны (для Ctrl+S)
