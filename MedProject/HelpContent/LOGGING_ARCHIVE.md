# Логирование

В этом разделе описано, как работает система логирования в приложении.

## 1. Что такое логирование

Логирование (журналирование) — это автоматическая запись событий и действий приложения в хронологическом порядке в специальные файлы (логи)

Система автоматически записывает в файл все важные события работы приложения:

- Запуск и остановка приложения
- Ошибки и предупреждения
- Операции с базой данных
- Действия пользователя (сохранение, удаление, редактирование)

Это помогает отслеживать проблемы и понимать, что происходило в системе.

## 2. Где находятся логи

Логи сохраняются в папке **`logs`** рядом с исполняемым файлом приложения.

Пути к папке логов:

Linux: `/opt/medproject/logs/`

Windows: `\medproject\logs\` (Полный путь расположения файлов выбирается пользователем при установке приложения. Воспользуйтесь поиском, если не знаете, где лежат файлы приложения)

**Важно:** Папка `logs` создаётся автоматически при первом запуске приложения.

## 3. Как открыть файл логов

1. В файловом менеджере (проводнике) Windows или Linux откройте папку logs, которая находится в директории medproject, и выберите файл логов за нужную дату.

2. Для того чтобы открыть логи в терминале Linux, сначала просмотрите список всех файлов в директории с логами. Для этого выполните команду: `ls -la /opt/medproject/logs/`. Она покажет подробный список всех файлов и директорий (включая скрытые), их размеры, даты изменения и права доступа.
Откройте нужный лог-файл с помощью текстового редактора, например nano: `nano /opt/medproject/logs/имя_нужного_файла.log`
Вместо имя_нужного_файла.log подставьте реальное имя файла, которое вы увидели после выполнения команды ls -la


## 4. Формат записей в логах

Каждая строка в логе содержит:

```
Дата и время | Уровень | Компонент | Сообщение
```

**Пример записи:**
```
2024-01-15 10:30:45.123|Info|HelpViewModel|HelpViewModel: инициализация тем справочника.
```

**Уровни логирования:**

- **Info** – информационные сообщения (обычная работа приложения)
- **Warn** – предупреждения (что-то необычное, но не критичное)
- **Error** – ошибки (проблемы, требующие внимания)
- **Debug** – отладочная информация (детали для разработчиков)

## 5. Что записывается в логи

**При запуске приложения:** инициализация базы данных, загрузка данных и справочников

**При работе пользователя:** открытие разделов (Ввод данных, Справочники, Справка), сохранение данных, редактирование и удаление записей и формирование отчётов

**При ошибках:** ошибки подключения к базе данных, валидации данных, ошибки при сохранении, критические ошибки приложения

## 6. Ротация логов

Ротация логов — это процесс автоматического управления файлами журналов: архивирование старых и удаление устаревших данных для экономии места на диске и предотвращения переполнения файловой системы

Система автоматически создаёт архивные копии логов:

- Каждый день создаётся новый файл лога
- Старые логи сохраняются с датой в имени файла
- Хранится максимум **7 архивных файлов**
- Старые файлы автоматически удаляются

**Пример файлов в папке `logs`:**
```
2026-04-20.log  ← лог за 20 апреля
2026-04-19.log  ← лог за 19 апреля
2026-04-18.log  ← лог за 18 апреля
```

## 7. Когда смотреть логи

Просматривайте логи в следующих случаях: приложение не запускается, ошибки при сохранении данных, проблемы с базой данных, непонятное поведение приложения.

## 8. Как искать в логах

В любом текстовом редакторе:

1. Нажмите **Ctrl + F**
2. Введите текст для поиска (например, `Error` или название операции)
3. Нажмите **Enter**

**Советы по поиску:**
- Ищите по уровню **`Error`** или **`Warn`** для быстрого нахождения проблем
- Ищите по дате, чтобы найти события в конкретный момент
- Ищите по названию операции (например, `Сохранение`)
