## Движение пациентов

В этом разделе описано, как рассчитываются показатели в отчёте по движению пациентов.  
Берется промежуток времени (месяц, квартал, полугодие, год) и значения из листа движения пациентов суммируются по всем датам периода.

### 1. Рассчет показателей движения пациентов


В отчёте каждая строка — это отделение, а столбцы формируются по данным «Листа движения пациентов» (по суткам) и суммируются/агрегируются за выбранный период (месяц, квартал, полугодие, год).

| Столбец отчета | Как формируется значение | Примечание |
|---|---|---|
| Количество коек | Берётся справочное количество коек по отделению на отчётный период | Если коечный фонд менялся внутри периода, используется значение/срез по правилам настроек отчёта (как правило — актуальное на дату формирования). |
| Состояло на начало истекших суток | Значение «состоит» на начало первых суток периода | Стартовое значение баланса движения; для последующих суток берётся «состоит» на начало соответствующих суток. |
| Поступило больных (всего) | Сумма всех поступлений в отделение за период | Поступления считаются как события «поступил» (не включают внутренние переводы). |
| Поступило сельских жителей | Сумма поступивших за период с признаком «сельский житель» | Подмножество «поступило (всего)». |
| Переведено из других отделений | Сумма переводов *в* отделение за период | Это прибытия переводом. |
| Переведено в другие отделения | Сумма переводов *из* отделения за период | Это выбытия переводом. |
| Выписано больных (всего) | Сумма всех выписок из отделения за период | Включает выписку домой и выбытие в другие стационары (если в учёте это «выписка»). |
| Выписано в другие стационары | Сумма выписок за период с признаком «в другой стационар» | Подмножество «выписано (всего)». |
| Умерло | Сумма случаев смерти в отделении за период | Учитывается как выбытие из отделения. |
| Состоит больных на начало текущего дня | Состояло на начало суток *после* последнего дня периода (т.е. итог баланса на конец периода) | Рассчитывается по суточному балансу: Состоит(конец суток) = Состояло(начало суток) + Поступило(всего) + Переведено из − Выписано(всего) − Переведено в − Умерло. |
| Состоит (в т.ч. сельских) | Количество состоящих на конец периода с признаком «сельский житель» | Детализация итогового «состоит». |
| Состоит матерей при детях | Количество «матерей при детях», состоящих на конец периода | Отдельный учёт по категории «матери при детях». |
| Выписано матерей | Сумма выбытий «матерей при детях» за период | Относится только к категории «матери при детях». |
| Факт койко-дней за период | Сумма ежедневных значений «состоит (всего)» по всем суткам периода | Факт койко-дней = Σ(Состоит всего на начало суток) (эквивалентно сумме «состоит» по суткам). |
| Койко-дни сельскими за период | Сумма ежедневных значений «состоит (сельских)» по всем суткам периода | Койко-дни сельских = Σ(Состоит сельских). |
| Койко-дни матерями за период | Сумма ежедневных значений «состоит матерей при детях» по всем суткам периода | Койко-дни матерей = Σ(Состоит матерей). |
| План койко-дней за период | Сумма плановых койко-дней за все дни периода (см. 2.1) | Для периодов из нескольких месяцев — через ежедневный план каждого месяца. |
| % выполнения плана | \(% = (Факт койко-дней / План койко-дней) × 100\) | Если план = 0, процент не рассчитывается/равен 0 по правилам системы. |


### 1.1. Уточнения по моменту времени («на начало суток»)

- **«Состояло на начало истекших суток»** в отчёте за период — это значение «состоит» **на начало первых суток периода** (старт баланса).
- **«Состоит больных на начало текущего дня»** — это значение «состоит» **на начало суток после последнего дня периода** (итог баланса на конец периода).
- **Суточный баланс**:
  - **Состоит(конец суток)** = **Состояло(начало суток)** + Поступило(всего) + Переведено из − Выписано(всего) − Переведено в − Умерло
  - **Состояло(начало следующих суток)** = **Состоит(конец текущих суток)**

### 1.2. Что считается поступлением/переводом/выпиской

- **Поступило (всего)**: события «поступил(а)» в отделение за период. Внутренние переводы сюда не входят.
- **Переведено из других отделений**: переводы в отделение (прибытия переводом).
- **Переведено в другие отделения**: переводы из отделения (выбытия переводом).
- **Выписано (всего)**: все выбытия «выписан(а)» за период.
- **Выписано в другие стационары**: часть «выписано (всего)» с указанием, что пациент выбыл в другой стационар.

### 1.3. Как считаются койко-дни за период

- **Факт койко-дней** — это сумма ежедневных значений «состоит (всего)» по всем суткам периода.
- Аналогично считаются **койко-дни сельскими** и **койко-дни матерями при детях**: суммируются ежедневные значения соответствующих показателей «состоит …».

> Важно: в формулах выше используется «состоит на начало суток» как ежедневное значение для суммирования. Если в системе принято суммировать «на конец суток», результат эквивалентен при стабильном определении «суток»; в спорных случаях ориентируйтесь на то, как заполнен «Лист движения пациентов» (какое поле там трактуется как «суточное состояние»).

### 1.4. Пограничные случаи

- **План койко-дней = 0**: показатель **«% выполнения плана»** не рассчитывается (или показывается 0) — по правилам системы отображения.
- **Изменение коечного фонда внутри периода**: значение в столбце **«Количество коек»** берётся по правилам настроек/среза отчёта (обычно — актуальное на дату формирования). Если в системе ведётся коечный фонд по дням, тогда корректнее учитывать его в плановых расчётах через ежедневный план (см. 2.1).

### 1.5. Пример расчёта (2 суток)

На **начало 01.04**: состояло 20.

**01.04**: поступило 6, переведено из 2, выписано 10, переведено в 2, умерло 0.  
**Состоит на начало 02.04** = 20 + 6 + 2 − 10 − 2 − 0 = **16**.

**02.04**: поступило 4, переведено из 1, выписано 3, переведено в 0, умерло 1.  
**Состоит на начало 03.04** = 16 + 4 + 1 − 3 − 0 − 1 = **17**.

Если период отчёта — **01.04–02.04**, то:
- **Состояло на начало истекших суток** = 20
- **Состоит больных на начало текущего дня** = 17 (на начало 03.04)
- **Факт койко-дней за период** = 20 + 16 = **36** (сумма «состоит» на начало суток 01.04 и 02.04)

### 2.1. Расчёт плана койко-дней для периодов

Для произвольного периода внутри одного месяца:

- **План за период** = Месячный план × (Дней в периоде / Дней в месяце)

Для периодов, охватывающих несколько месяцев (квартал/полугодие/год):

- **Ежедневный план** = Месячный план / Количество дней в этом месяце
- **План за период** = Сумма ежедневных планов за все дни периода
