## Работа коек

В этом разделе описано, как рассчитываются показатели во 2‑м отчёте по работе коечного фонда.  
Используется **единая логика терминов**, согласованная с реализованными формулами в системе.

### 1. Основные понятия

- **Койко-день** – один день пребывания пациента на одной койке.
- **Плановое число коек** – количество коек, утверждённое для отделения/больницы.
- **Календарные дни периода** – количество дней в анализируемом периоде (например, в январе – 31 день, в квартале – 90/91, в году – 365/366).
- **Выбывшие пациенты** – пациенты, лечение которых в данном отделении завершено: **выписано + умерло** (без переведённых).
- **Пролеченные пациенты** – все пациенты, которые прошли через отделение за период: **выписано + умерло + переведено**.
- **Пользованные больные** – усреднённый показатель нагрузки: **(Поступило + Выписано + Умерло) / 2**.

### 2. Формулы (таблица)

| Показатель                       | Что показывает                                                | Формула (логика системы)                                                                                 | Комментарий |
|----------------------------------|---------------------------------------------------------------|----------------------------------------------------------------------------------------------------------|-------------|
| План койко-дней                  | Максимально возможное использование коек                     | План койко-дней = Сумма ежедневных планов за период, где ежедневный план = Месячный план / Дней в месяце | Используется для расчёта процента выполнения плана и занятости. |
| Факт койко-дней                  | Сколько койко-дней реально отработано                        | Факт койко-дней = сумма всех дней пребывания пациентов                                                  | Берётся из движения пациентов. |
| Коэффициент использования коек   | Насколько полно были загружены койки                         | Коэффициент (%) = (Факт койко-дней / План койко-дней) × 100                                              | 80–90% и выше — хорошая загрузка. |
| Средняя занятость койки в день   | Сколько коек в среднем занято ежедневно                      | Средняя занятость (койки) = Факт койко-дней / Число календарных дней                                    | Связан с коэффициентом использования. |
| Средняя длительность пребывания  | На сколько дней в среднем пациент ложится в отделение        | **СДП (дней) = Факт койко-дней / Число пролеченных пациентов**                                          | В знаменателе используются **пролеченные**: выписано + умерло + переведено. |
| Оборот койки                     | Сколько пациентов пролежало на одной койке за период         | **Оборот койки = Число пролеченных пациентов / Среднее число коек**                                     | Оценивает интенсивность использования коек. |
| Средний простой койки            | Сколько дней в среднем койка простаивает                     | Средний простой = (Дни в периоде − (Факт койко-дней / среднее число коек)) / Оборот койки               | Оборот считается по **пролеченным**, поэтому и здесь используется эта логика. |
| Летальность                      | Доля умерших среди выбывших пациентов                        | Летальность (%) = (Умерло / (Выписано + Умерло)) × 100                                                   | В знаменателе **только выбывшие**: выписано + умерло (без переведённых). |
| Пользованные больные             | Усреднённое количество больных, участвовавших в движении     | Пользованные = (Поступило + Выписано + Умерло) / 2                                                       | Используется как вспомогательный показатель нагрузки. |

Обратите внимание:  
- Для **СДП**, **оборота койки** и **среднего простоя** в системе осознанно используются **пролеченные пациенты** (выписано + умерло + переведено).  
- Для **летальности** используются только **выбывшие** (выписано + умерло), что соответствует классической медицинской статистике.

### 2.1. Расчёт плана койко-дней для длительных периодов

Для периодов, охватывающих несколько месяцев, квартал, полгода или год, план рассчитывается следующим образом:

**Принцип расчёта:**
- **Ежедневный план** = Месячный план / Количество дней в этом месяце
- **План за период** = Сумма ежедневных планов за все дни периода

**Примеры:**
- **Квартал (3 месяца):** План = Сумма планов за каждый день квартала (с учётом разного количества дней в месяцах: 28/29, 30, 31)
- **Полгода (6 месяцев):** План = Сумма планов за каждый день полугодия
- **Год (12 месяцев):** План = Сумма планов за каждый день года

**Важно:** Система автоматически учитывает:
- Разное количество дней в месяцах (28/29, 30, 31)
- Изменения месячного плана в течение периода (если план менялся)
- Точное количество дней в выбранном периоде

### 3. Пример расчёта

Пусть за месяц в отделении:

- Коек: 40
- Дней в месяце: 30
- Факт койко-дней: 980
- Выписано: 80 пациентов
- Умерло: 5 пациентов
- Переведено в другие отделения: 10 пациентов

Тогда:

- **Выбывшие** = 80 + 5 = 85  
- **Пролеченные** = 80 + 5 + 10 = 95

Расчёты:

1. **План койко-дней:**  
   `40 × 30 = 1200`

2. **Коэффициент использования коек:**  
   `(980 / 1200) × 100 ≈ 81,7%`

3. **Средняя занятость койки в день:**  
   `980 / 30 ≈ 32,7 койки`

4. **Средняя длительность пребывания (по пролеченным):**  
   `980 / 95 ≈ 10,3 дня`

5. **Оборот койки (по пролеченным):**  
   `95 / 40 ≈ 2,375 пациента на койку за месяц`

6. **Средний простой койки (концептуально):**  
   `(1200 - 980) / 40 = 220 / 40 = 5,5 дня` (в SQL используется эквивалентная формула через СДП и оборот)

7. **Летальность (по выбывшим):**  
   `(5 / (80 + 5)) × 100 ≈ 5,6%`

Такая связка показателей позволяет:

- оценить полноту использования коечного фонда;
- понять интенсивность работы койки (через оборот по **пролеченным**);
- видеть реальную тяжесть контингента (через СДП и летальность по **выбывшим**);
- контролировать избыточный простой коек.
