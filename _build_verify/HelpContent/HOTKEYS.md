# Горячие клавиши

В приложении "Коечный учёт" доступны следующие горячие клавиши для ускорения работы:

## Навигация по разделам

| Горячая клавиша | Действие |
|----------------|----------|
| **Ctrl+1** | Перейти в раздел "Ввод данных" |
| **Ctrl+2** | Перейти в раздел "Справочники" |
| **Ctrl+3** | Перейти в раздел "Справка" |

## Раздел "Ввод данных"

| Горячая клавиша | Действие |
|----------------|----------|
| **Ctrl+S** | Сохранить данные |
| **Ctrl+R** | Открыть отчёт "Движение больных" |
| **Ctrl+Shift+R** | Открыть отчёт "Работа коек" |
| **Enter** | Перейти к следующей строке в таблице |
| **Стрелки (←→↑↓)** | Перемещение между ячейками таблицы |

### Примечания:
- **Ctrl+S** работает только если данные валидны и не находятся в режиме архива
- При нажатии **Enter** курсор автоматически переходит к первой редактируемой ячейке следующей строки
- Используйте стрелки для быстрого перемещения между полями ввода

## Раздел "Справочники"

### Общие действия

| Горячая клавиша | Действие |
|----------------|----------|
| **Ctrl+N** | Добавить новую запись (в текущей вкладке) |
| **F2** | Редактировать выбранную запись |
| **Delete** | Удалить выбранную запись |

### Примечания:
- **F2** и **Delete** работают только если в таблице выбрана запись
- При удалении система запросит подтверждение
- Нельзя удалить запись, если к ней привязаны другие данные

## Работа с таблицами

| Горячая клавиша | Действие |
|----------------|----------|
| **Enter** | Сохранить изменения в текущей ячейке и перейти к следующей строке |
| **Tab** | Перейти к следующей ячейке (стандартное поведение WPF) |
| **Shift+Tab** | Перейти к предыдущей ячейке |
| **Стрелки** | Перемещение между ячейками |
| **Delete** | Очистить содержимое ячейки (в режиме редактирования) |

## Советы по использованию

1. **Используйте навигацию по разделам** (Ctrl+1, Ctrl+2, Ctrl+3) для быстрого переключения между основными разделами приложения

2. **Сохраняйте данные регулярно** (Ctrl+S) - это поможет избежать потери данных при случайном закрытии приложения

3. **Используйте горячие клавиши в справочниках** для быстрого добавления, редактирования и удаления записей без использования мыши

4. **Enter в таблицах** - удобный способ быстро заполнить данные по всем строкам, не используя мышь

5. **F2 и Delete** работают только когда в таблице выбрана строка - используйте клик мыши или клавиши со стрелками для выбора

## Дополнительная информация

Все горячие клавиши также отображаются в подсказках (ToolTip) при наведении курсора на соответствующие кнопки в интерфейсе.

Если горячая клавиша не работает, убедитесь, что:
- Вы находитесь в правильном разделе приложения
- Выбран нужный элемент (для F2 и Delete)
- Данные валидны (для Ctrl+S)
- Вы не находитесь в режиме архива (для Ctrl+S)
