# Сборка и запуск (Linux / Windows)

Приложение «Коечный учёт» собирается как настольное решение на **.NET 8** и **Avalonia**. Основная целевая платформа — **Linux**; сборка под **Windows** выполняется тем же способом с другим идентификатором среды выполнения (RID).

## Что нужно для сборки

- **[.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0)** (версии 8.0.x), установленная на машине разработчика или CI.
- Исходный код решения (проект UI обычно находится в каталоге с `MedProject.csproj`).

Сборку можно выполнять **на Linux под Linux**, **на Windows под Windows**, а также **кросс-компиляцию** (например, на Windows установить SDK и собрать `linux-x64`).

## Публикация под Linux (основной сценарий)

Перейдите в корень решения (где лежит файл решения `.sln`) или укажите полный путь к проекту.

**Самодостаточная сборка** (на целевой машине не требуется установленный .NET Runtime — удобно для раздачи одной папкой):

```bash
dotnet publish MedProject/MedProject.csproj -c Release -r linux-x64 --self-contained true
```

Готовые файлы появятся в:

`MedProject/bin/Release/net8.0/linux-x64/publish/`

Запуск с терминала (имя исполняемого файла совпадает с именем проекта, без расширения `.exe`):

```bash
chmod +x ./MedProject
./MedProject
```

**Другие архитектуры Linux** (при необходимости):

- 64-bit ARM: `-r linux-arm64`
- Уточните RID для своей платформы в [документации RID](https://learn.microsoft.com/dotnet/core/rid-catalog).

**Сборка с общей зависимостью от установленного в системе .NET** (меньший размер папки; на компьютере пользователя должна быть установлена **[.NET Runtime 8](https://dotnet.microsoft.com/download/dotnet/8.0)** для соответствующей ОС):

```bash
dotnet publish MedProject/MedProject.csproj -c Release -r linux-x64 --self-contained false
```

На целевой системе должна быть установлена та же мажорная версия runtime (**8.0**), что используется при сборке.

### Зависимости Linux при framework-dependent сборке

Если приложение запускается через установленный в системе `dotnet`, могут понадобиться типичные для GUI-библиотеки дистрибутива (набор зависит от ОС): например, **fontconfig**, **libICE**, **SM**, **gtk**/зависимости оконной подсистемы X11 или Wayland. При **self-contained** часть окружения поставляется вместе с приложением; при ошибках запуска установите рекомендуемые для Avalonia пакеты вашего дистрибутива или используйте **self-contained** сборку.

## Публикация под Windows (при необходимости)

Из корня решения:

```bash
dotnet publish MedProject/MedProject.csproj -c Release -r win-x64 --self-contained true
```

Выходной каталог:

`MedProject/bin/Release/net8.0/win-x64/publish/`

Запуск: двойной щелчок по `MedProject.exe` или запуск из командной строки.

Кросс-сборка **linux-x64** на машине с Windows обычно поддерживается SDK из коробки; при ошибках убедитесь, что установлены актуальный SDK 8 и рабочая загрузка пакетов NuGet (`dotnet restore`).

## Что переносить на компьютер пользователя

Для развёртывания скопируйте **всё содержимое** каталога `publish` (исполняемый файл, `.dll`, при self-contained — файлы runtime, папку `HelpContent` с файлами `.md`, `appsettings.json`, `NLog.config` и т.д.). Файл базы **`HospitalStatistics.db`** создаётся при первом запуске рядом с приложением — его можно не копировать при первичной установке.

## Краткая справка по параметрам

| Параметр | Назначение |
|----------|------------|
| `-c Release` | оптимизированная сборка для использования |
| `-r linux-x64` / `-r win-x64` | целевая ОС и архитектура |
| `--self-contained true` | приложение со встроенным runtime (удобнее для Linux без установки .NET) |
| `--self-contained false` | нужен установленный .NET 8 Runtime на целевой машине |

После установки или копирования папки пользователь запускает программу так же, как описано в разделе справки **«Быстрый старт»** (запуск под Linux и Windows).
