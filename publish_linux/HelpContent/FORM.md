# Ввод данных

Раздел «Ввод данных» — основное рабочее место для ежедневного учёта движения пациентов по каждому типу коек.

## 1. Как устроен экран

Экран состоит из трёх частей:

1. **Панель выбора** — отделение и дата в верхней части
2. **Таблица ввода** — строки по типам коек с колонками движения
3. **Панель кнопок** — сохранение и формирование отчётов внизу

## 2. Выбор отделения и даты

В верхней части экрана расположены два элемента:

- **Отделение** — выпадающий список всех отделений. Выберите нужное отделение перед вводом данных.
- **Дата** — календарь для выбора даты листка учёта. По умолчанию установлена **сегодняшняя дата**.

> **Важно:** При смене отделения, если есть несохранённые данные, система спросит подтверждение — несохранённые изменения будут потеряны.

После выбора отделения и даты таблица автоматически загружает данные за этот день (если они уже были введены ранее) или показывает пустые строки.

## 3. Колонки таблицы

Каждая строка таблицы соответствует одному **типу коек** в выбранном отделении.

### 3.1. Информационные колонки (только чтение)

| Колонка | Описание |
|---------|----------|
| **Наименование** | Название типа коек (например: «Терапевтические») |
| **Код** | Числовой код типа коек |
| **Фактически развёрнуто коек** | Количество коек этого типа в отделении на выбранную дату (берётся из справочника) |

### 3.2. Движение больных за истекшие сутки

Эти поля описывают события, произошедшие **за прошедший день**.

| Колонка | Описание | Ограничения |
|---------|----------|-------------|
| **Состояло на начало суток** | Сколько пациентов было на начало дня | Не может превышать количество коек |
| **Поступило — Всего** | Всего поступило пациентов | ≥ 0 |
| **Поступило — Сельских жителей** | Из числа поступивших — жители сельской местности | ≤ «Всего поступило» |
| **Поступило — Детей до 14 лет** | Из числа поступивших — дети до 14 лет | ≤ «Всего поступило» |
| **Переведено из других отделений** | Переведено внутри больницы из других отделений | ≥ 0 |
| **Переведено в другие отделения** | Переведено внутри больницы в другие отделения | ≥ 0 |
| **Выписано — Всего** | Всего выписано пациентов | ≤ «Состояло на начало суток» |
| **Выписано — в т.ч. в другие стационары** | Из числа выписанных — переведены в другие больницы | ≤ «Всего выписано» |
| **Умерло** | Количество умерших | ≤ «Состояло на начало суток» |

### 3.3. На начало текущего дня

Эти поля описывают состояние **на конец прошедшего дня / начало текущего**.

| Колонка | Описание | Примечание |
|---------|----------|------------|
| **Состоит — Всего** | Итоговое количество пациентов на конец дня | **Рассчитывается автоматически**, недоступно для ввода |
| **Состоит — в т.ч. сельских** | Из числа состоящих — жители сельской местности | ≤ «Состоит всего» |
| **Состоит матерей при детях** | Матери, находящиеся вместе с детьми | ≥ 0 |
| **Выписано матерей** | Матери, выписанные в этот день | ≥ 0 |

### 3.4. Формула расчёта «Состоит всего»

```
Состоит всего = Состояло на начало суток
              + Поступило всего
              + Переведено из других отделений
              - Выписано всего
              - Переведено в другие отделения
              - Умерло
```

Это значение рассчитывается автоматически и отображается в колонке **«Состоит — Всего»**.

## 4. Ввод данных в ячейки

- Нажмите на ячейку, чтобы начать редактирование
- Вводите только целые числа (буквы и символы не принимаются)
- **Enter** — сохранить значение и перейти к следующей строке
- **Стрелки (←→↑↓)** — перемещение между ячейками
- **Tab / Shift+Tab** — переход к следующей / предыдущей ячейке

## 5. Ошибки валидации

Если введены некорректные данные, ячейка выделяется **красной рамкой**.

- При наведении курсора на ячейку с ошибкой появляется **всплывающая подсказка** с объяснением ошибки
- Сохранение невозможно, пока есть ошибки
- Кнопка **«Сохранить данные»** будет неактивна

**Примеры ошибок:**
- «Сельских жителей не может быть больше, чем всего поступило»
- «Выписано не может быть больше, чем состояло на начало суток»
- «Состоит сельских не может быть больше, чем состоит всего»

## 6. Межсуточная проверка

Система автоматически проверяет, что данные последовательны между днями:

```
Состояло на начало суток (сегодня) = Состоит всего (вчера)
```

Если значения не совпадают, ячейка «Состояло на начало суток» выделяется красной рамкой с предупреждением.

**Как исправить:** Введите значение, равное «Состоит всего» предыдущего дня, или скорректируйте данные за предыдущий день.

## 7. Сохранение данных

После заполнения всех строк нажмите кнопку **«Сохранить данные»** или используйте **Ctrl+S**.

- Кнопка активна только если нет ошибок валидации
- После успешного сохранения данные записываются в базу
- Сохранение работает для выбранного отделения и выбранной даты

> **Совет:** Сохраняйте данные после заполнения каждого отделения, не накапливайте несохранённые изменения.

## 8. Формирование отчётов

В нижней левой части экрана находятся две кнопки для создания PDF-отчётов.

### 8.1. Кнопки отчётов

| Кнопка | Горячая клавиша | Что формирует |
|--------|----------------|---------------|
| **Отчёт — движение больных** | Ctrl+R | Отчёт №1 по движению пациентов |
| **Отчёт — работа коек** | Ctrl+Shift+R | Отчёт №2 по работе коечного фонда |

### 8.2. Диалог выбора периода

При нажатии на любую кнопку отчёта открывается окно выбора диапазона дат:

1. **Начальная дата** — первый день отчётного периода
2. **Конечная дата** — последний день отчётного периода
3. Нажмите **«Сформировать отчёт»** — система рассчитает показатели за указанный период
4. Нажмите **«Отмена»** — закрыть окно без формирования отчёта

Во время формирования отображается **индикатор загрузки**. После завершения PDF-файл автоматически открывается в программе для просмотра документов, установленной на компьютере.

> **Важно:** Если за выбранный период нет введённых данных, отчёт будет пустым или содержать нули.

### 8.3. Рекомендуемые периоды

- **За сутки:** начало = конец = нужная дата
- **За месяц:** начало = 1-е число, конец = последнее число месяца
- **За квартал:** начало = 1 января/апреля/июля/октября, конец = 31 марта/30 июня/30 сентября/31 декабря
- **За год:** начало = 1 января, конец = 31 декабря

## 9. Типичные сценарии работы

### Ежедневный ввод данных

1. Перейдите в раздел **«Ввод данных»** (Ctrl+1)
2. Выберите нужное **отделение**
3. Убедитесь, что установлена правильная **дата** (по умолчанию — сегодня)
4. Заполните строки по каждому типу коек
5. Проверьте, нет ли красных ячеек
6. Нажмите **«Сохранить данные»** (Ctrl+S)
7. При необходимости переключитесь на другое отделение и повторите

### Исправление ранее введённых данных

1. Выберите нужное отделение и установите нужную дату в календаре
2. Таблица загрузит ранее сохранённые значения
3. Измените нужные ячейки
4. Сохраните изменения (Ctrl+S)
