# Логирование

В этом разделе описано, как работает система логирования в приложении.

## 1. Что такое логирование

Система автоматически записывает в файл все важные события работы приложения:

- Запуск и остановка приложения
- Ошибки и предупреждения
- Операции с базой данных
- Действия пользователя (сохранение, удаление, редактирование)

Это помогает отслеживать проблемы и понимать, что происходило в системе.

## 2. Где находятся логи

Логи сохраняются в папке **`logs`** рядом с исполняемым файлом приложения.

**Путь к файлу логов:**
```
<папка приложения>\logs\log.txt
```

**Важно:** Папка `logs` создаётся автоматически при первом запуске приложения.

## 3. Как открыть файл логов

**Способ 1: Через Проводник Windows**

1. Откройте папку, в которой находится приложение
2. Зайдите в папку **`logs`**
3. Дважды щёлкните по файлу **`log.txt`**
4. Файл откроется в Блокноте или другом текстовом редакторе

**Способ 2: Через Win + R**

1. Нажмите **Win + R** (откроется окно «Выполнить»)
2. Введите полный путь к файлу лога
3. Нажмите **Enter**

**Способ 3: Через поиск Windows**

1. Нажмите клавишу **Win**
2. Введите в поиск: **`log.txt`**
3. Найдите файл в папке `logs` приложения

## 4. Формат записей в логах

Каждая строка в логе содержит:

```
Дата и время | Уровень | Компонент | Сообщение
```

**Пример записи:**
```
2024-01-15 10:30:45.123|Info|HelpViewModel|HelpViewModel: инициализация тем справочника.
```

**Уровни логирования:**

- **Info** – информационные сообщения (обычная работа приложения)
- **Warn** – предупреждения (что-то необычное, но не критичное)
- **Error** – ошибки (проблемы, требующие внимания)
- **Debug** – отладочная информация (детали для разработчиков)

## 5. Что записывается в логи

**При запуске приложения:**
- Инициализация базы данных
- Загрузка данных и справочников

**При работе пользователя:**
- Открытие разделов (Ввод данных, Справочники, Справка)
- Сохранение данных
- Редактирование и удаление записей
- Формирование отчётов

**При ошибках:**
- Ошибки подключения к базе данных
- Ошибки валидации данных
- Ошибки при сохранении
- Критические ошибки приложения

## 6. Ротация логов

Система автоматически создаёт архивные копии логов:

- Каждый день создаётся новый файл лога
- Старые логи сохраняются с датой в имени файла
- Хранится максимум **7 архивных файлов**
- Старые файлы автоматически удаляются

**Пример файлов в папке `logs`:**
```
log.txt             ← текущий лог
log.2024-01-14.txt  ← лог за 14 января
log.2024-01-13.txt  ← лог за 13 января
```

## 7. Когда смотреть логи

Просматривайте логи в следующих случаях:

1. **Приложение не запускается** – проверьте ошибки при инициализации
2. **Ошибки при сохранении данных** – найдите причину в логах
3. **Проблемы с базой данных** – логи покажут детали ошибки
4. **Непонятное поведение приложения** – логи покажут, что происходило

## 8. Как искать в логах

**В Блокноте:**
1. Нажмите **Ctrl + F**
2. Введите текст для поиска (например, `Error` или название операции)
3. Нажмите **Enter**

**Советы по поиску:**
- Ищите по уровню **`Error`** или **`Warn`** для быстрого нахождения проблем
- Ищите по дате, чтобы найти события в конкретный момент
- Ищите по названию операции (например, `Сохранение`)

## 9. Настройки логирования

Логирование настраивается в файле **`NLog.config`** в папке приложения. Основные параметры:

- **Файл логов:** `logs/log.txt`
- **Ротация:** ежедневно
- **Хранение:** 7 дней
- **Уровень:** Info и выше
