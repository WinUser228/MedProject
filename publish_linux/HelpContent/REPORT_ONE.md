# Отчёт №1: Движение пациентов в стационаре

В этом разделе описано, как рассчитываются показатели в 1-м отчёте о движении пациентов. Все формулы приведены с числовыми примерами.

## 1. Основные понятия

- **Состояло на начало дня** – количество пациентов, которые находились в отделении на начало отчётных суток.
- **Поступило** – количество пациентов, поступивших в отделение за сутки.
- **Выписано** – количество пациентов, выписанных из отделения за сутки.
- **Койко-день** – один день пребывания одного пациента в стационаре.

## 2. Основная формула движения пациентов

Главная формула, по которой рассчитывается количество пациентов на конец дня:

**Формула:**
```
Состоит всего (на конец дня) = Состояло на начало дня 
                                + Всего поступило 
                                + Переведено из других отделений
                                - Всего выписано
                                - Переведено в другие отделения
                                - Умерло
```

**Пример:**  
На начало дня состояло: 25 пациентов  
За день поступило: 8 пациентов  
Переведено из других отделений: 2 пациента  
Выписано всего: 5 пациентов  
Переведено в другие отделения: 1 пациент  
Умерло: 0 пациентов

```
Состоит всего = 25 + 8 + 2 - 5 - 1 - 0 = 29 пациентов
```

**Важно:** Значение "Состоит всего" рассчитывается автоматически и не вводится вручную.

## 3. Ввод данных за сутки

### 3.1. Обязательные поля

Для каждого типа койки в отделении необходимо заполнить:

- **Состояло на начало дня** – обязательно
- **Всего поступило** – обязательно
- **Всего выписано** – обязательно
- **Умерло** – обязательно (может быть 0)

### 3.2. Дополнительные поля

- **Поступило сельских жителей** – необязательно, но не может быть больше, чем "Всего поступило"
- **Поступило детей до 14 лет** – необязательно, но не может быть больше, чем "Всего поступило"
- **Переведено из других отделений** – необязательно
- **Переведено в другие отделения** – необязательно
- **Выписано в другие стационары** – необязательно, но не может быть больше, чем "Всего выписано"
- **Выписано матерей** – необязательно, но не может быть больше, чем "Всего выписано"
- **Состоит сельских жителей** – необязательно, но не может быть больше, чем "Состоит всего"
- **Состоит матерей** – необязательно, но не может быть больше, чем "Состоит всего"

## 4. Межсуточная проверка

Система автоматически проверяет связь между днями:

**Формула проверки:**
```
Состояло на начало дня (сегодня) = Состоит всего (вчера)
```

**Пример:**  
Вчера на конец дня состояло: 29 пациентов  
Сегодня на начало дня должно быть: 29 пациентов

Если значения не совпадают, система покажет предупреждение.

## 5. Расчёт показателей за период

### 5.1. План койко-дней

Плановое количество койко-дней рассчитывается на основе месячного плана, установленного для каждого типа койки.

**Формула для произвольного периода:**
```
План койко-дней за период = Месячный план × (Количество дней в периоде / Количество дней в месяце)
```

**Пример:**  
Месячный план: 900 койко-дней  
Период: 15 дней  
Дней в месяце: 30

```
План койко-дней = 900 × (15 / 30) = 450 койко-дней
```

**Расчёт плана для длительных периодов:**

Для периодов, охватывающих несколько месяцев, квартал, полгода или год, план рассчитывается как сумма планов за каждый день периода:

- **Ежедневный план** = Месячный план / Количество дней в этом месяце
- **План за период** = Сумма ежедневных планов за все дни периода

**Примеры:**

- **Квартал (3 месяца):** План = Сумма планов за каждый день квартала (с учётом разного количества дней в месяцах)
- **Полгода (6 месяцев):** План = Сумма планов за каждый день полугодия
- **Год (12 месяцев):** План = Сумма планов за каждый день года

**Важно:** Система автоматически учитывает разное количество дней в месяцах (28/29, 30, 31) и изменения месячного плана в течение периода.

### 5.2. Факт койко-дней (проведено койко-дней)

Это сумма значений "Состоит всего" за все дни периода.

**Формула:**
```
Факт койко-дней = Сумма (Состоит всего) за все дни периода
```

**Пример:**  
За 5 дней значения "Состоит всего" были: 25, 28, 27, 29, 30

```
Факт койко-дней = 25 + 28 + 27 + 29 + 30 = 139 койко-дней
```

### 5.3. Процент выполнения плана

Показывает, насколько выполнен план по использованию коек.

**Формула:**
```
Процент выполнения плана (%) = (Факт койко-дней / План койко-дней) × 100
```

**Пример:**  
План койко-дней: 450  
Факт койко-дней: 139

```
Процент выполнения = (139 / 450) × 100 ≈ 30,9%
```

**Интерпретация:** План выполнен на 30,9%. Значение меньше 100% означает недовыполнение плана.

### 5.4. Проведено койко-дней сельскими жителями

Сумма значений "Состоит сельских жителей" за все дни периода.

**Формула:**
```
Койко-дни сельских = Сумма (Состоит сельских жителей) за все дни периода
```

**Пример:**  
За 5 дней значения "Состоит сельских жителей" были: 8, 9, 8, 10, 11

```
Койко-дни сельских = 8 + 9 + 8 + 10 + 11 = 46 койко-дней
```

### 5.5. Проведено койко-дней матерями

Сумма значений "Состоит матерей" за все дни периода.

**Формула:**
```
Койко-дни матерей = Сумма (Состоит матерей) за все дни периода
```

**Пример:**  
За 5 дней значения "Состоит матерей" были: 3, 4, 3, 4, 5

```
Койко-дни матерей = 3 + 4 + 3 + 4 + 5 = 19 койко-дней
```

## 6. Итоговая связка примера

Пусть за 5 дней были следующие данные:

**День 1:**
- Состояло на начало: 25
- Поступило: 8
- Выписано: 5
- Умерло: 0
- Состоит всего: 25 + 8 - 5 - 0 = 28
- Состоит сельских: 8
- Состоит матерей: 3

**День 2:**
- Состояло на начало: 28 (равно "Состоит всего" вчера)
- Поступило: 6
- Выписано: 6
- Умерло: 0
- Состоит всего: 28 + 6 - 6 - 0 = 28
- Состоит сельских: 9
- Состоит матерей: 4

**День 3:**
- Состояло на начало: 28
- Поступило: 5
- Выписано: 6
- Умерло: 0
- Состоит всего: 28 + 5 - 6 - 0 = 27
- Состоит сельских: 8
- Состоит матерей: 3

**День 4:**
- Состояло на начало: 27
- Поступило: 9
- Выписано: 7
- Умерло: 0
- Состоит всего: 27 + 9 - 7 - 0 = 29
- Состоит сельских: 10
- Состоит матерей: 4

**День 5:**
- Состояло на начало: 29
- Поступило: 7
- Выписано: 6
- Умерло: 0
- Состоит всего: 29 + 7 - 6 - 0 = 30
- Состоит сельских: 11
- Состоит матерей: 5

**Итоги за период:**

1. **Факт койко-дней:**  
   `28 + 28 + 27 + 29 + 30 = 142 койко-дня`

2. **Койко-дни сельских:**  
   `8 + 9 + 8 + 10 + 11 = 46 койко-дней`

3. **Койко-дни матерей:**  
   `3 + 4 + 3 + 4 + 5 = 19 койко-дней`

4. **Процент выполнения плана** (если план был 200 койко-дней):  
   `(142 / 200) × 100 = 71%`

## 7. Важные правила валидации

Система автоматически проверяет следующие правила:

1. **Состояло на начало дня** не может превышать количество коек
2. **Поступило сельских** не может быть больше, чем **Всего поступило**
3. **Поступило детей** не может быть больше, чем **Всего поступило**
4. **Выписано в другие стационары** не может быть больше, чем **Всего выписано**
5. **Выписано матерей** не может быть больше, чем **Всего выписано**
6. **Состоит сельских** не может быть больше, чем **Состоит всего**
7. **Состоит матерей** не может быть больше, чем **Состоит всего**
8. **Умерло** не может быть больше, чем **Состояло на начало дня**
9. **Состояло на начало дня** не может быть меньше, чем **Всего выписано** за этот день
10. Сумма **Состояло на начало дня** + **Всего поступило** не может превышать количество коек

При нарушении любого из этих правил система покажет сообщение об ошибке.
