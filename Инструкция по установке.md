MedProject («Коечный учёт»)

Описание программы
======================================================
Настольное приложение на .NET 8 + Avalonia для ежедневного учёта движения пациентов и формирования отчётов.

Для работы приложения необходимо:
- Операционная система:  дистрибутивы Linux использующие менеджер пакетов rpm 
(установка пакета программы через rpm), а также поддерживается Windows 10 или выше (графический установщик).

- Среда выполнения .NET: при самодостаточной (self-contained) сборке отдельно устанавливать .NET не нужно.

- База данных: SQLite — файл `HospitalStatistics.db` создаётся автоматически при первом запуске в 
каталоге данных пользователя (не в папке с программой): на Linux это `~/.local/share/MedProject/`, 
на Windows — `%LOCALAPPDATA%\MedProject\`. Отдельный сервер баз данных не требуется.

- Просмотр отчётов: любая программа для открытия PDF-файлов (в Linux — штатный просмотрщик или браузер; 
в Windows — например Adobe Acrobat Reader или браузер)

Основные пути установки:

- Файлы программы: `/opt/medproject/`
- Команда запуска: `/usr/bin/medproject`
- Ярлык в меню: `/usr/share/applications/medproject.desktop`
- Иконка: `/usr/share/pixmaps/medproject.ico`

Установка
==============================================================

1. Установка RPM

Скопируйте RPM‑файл (`medproject-1.0.0-1*.x86_64.rpm`) на компьютер пользователя, например в домашнюю директорию
Перейдите в папку, где лежит RPM. (Команда cd, если файл находиться в домашней директории)
Установите пакет (локальный файл — поэтому нужен префикс `./`): sudo dnf install ./medproject-*.x86_64.rpm

2. После установки приложение появится в меню и будет доступна команда запуска из терминала `medproject`. Можно создать ярлык на рабочем столе, перетащив значок программы из меню

3. Проверка после установки (Необязательно)

Проверить, что пакет установлен: rpm -q medproject
Посмотреть, какие файлы поставил пакет: rpm -ql medproject

Проблемы при установке

- Ошибка про зависимости / “nothing provides …” : установите недостающий пакет, который предлагает `dnf` (обычно это системная библиотека).
- RPM не найден : убедитесь, что вы в нужной папке и используете `./имя.rpm`.


Удаление программы
==============================================================

Удаление программы: sudo dnf remove medproject

При удалении пакета данные пользователя не удаляются автоматически (база и настройки остаются в домашней папке). Если нужен полный сброс, удалите их вручную.


Логрование
==============================================================

Логи сохраняются в каталоге `logs` рядом с файлами установленной программы. Также логирование происходит в терминале при запуске приложения через него.
